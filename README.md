# blackjack_game
Interactive Blackjack game that outputs a win, lose or push outcome based on the value of the dealers' and players' hand.

# Features
- Randomly generates cards for the player and dealer.
- Allows the player to choose whether to hit or stand.
- Uses loops to manage additional card draws.
- Automatically draws cards for the dealer until their hand reaches at least 17.
- Compares the final hand values to determine the game outcome.

# Skills Used
- Python
- Conditional Statements
- While Loops
- User Input
- Random Number Generation
- Debugging

# How to Run
1. Download `blackjack_game.py`.
2. Open the file in a Python environment.
3. Run the program and follow the prompts to play.
